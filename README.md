# TP1 - Sistema de Gestão de Biblioteca Universitária

**Aluna:** Laura Cristina Gomides Jubé  
**Disciplina:** Projeto de Bloco: Desenvolvimento em Back-End [26E4_5]  
**Trilha:** Java (JDK 21 + IntelliJ IDEA Community)

## Conteúdo

- `docs/` - documento de requisitos, casos de uso, diagrama de casos de uso, justificativa de escopo e o relatório em PDF (`LAURA_JUBE_PB_TP1.pdf`)
- `src/` - programa standalone inicial em Java (`Main.java`)

## Como executar

Abrir o projeto no IntelliJ IDEA com o JDK 21, abrir `src/Main.java` e clicar em **Run**.

Ou pelo terminal:

```
javac -d out src/Main.java
java -cp out Main
```
